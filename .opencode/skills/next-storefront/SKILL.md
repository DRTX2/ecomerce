# Next Storefront

- Prefer server-rendered catalog data with explicit loading, empty, and unavailable states.
- Treat backend contracts as typed external inputs; do not invent catalog data or trust client-calculated prices.
- Keep the first-load JavaScript small and avoid client components unless interaction requires them.
- Meet keyboard, semantic HTML, color contrast, mobile, and reduced-motion expectations.
- Run production builds before completion and do not expose long-lived credentials in browser code.
